# Optional Sound Files

The game generates simple notification beeps automatically so it works out of the box.

If you want custom sounds, place `.wav` files here with these exact names:

- `feed.wav`
- `clean.wav`
- `play.wav`
- `sleep.wav`
- `med.wav`
- `learn.wav`
- `sick.wav`
- `low.wav`
- `click.wav`
- `success.wav`
- `fail.wav`

They will override the generated tones.
